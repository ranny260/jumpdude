Hi, today im gonna tell you how i created a game with 11 years. Long ago, i wanted to create a game with my dad, then i learned some things of programming.
When my dad told me if i wanted to create a game now that i know more things, i accepted, that wasnt long ago.
We decided to make a game similar to the dino game in google.
We were going to build our game with python, its an easy-to-learn language, but pretty powerful. Very used in the world of AI, talking about AI, we didnt use it to make our game at all.
Then we started watching a tutorial of how to build a game in pygame, pygame is a library to help developers making a game in python. 
While we were watching the video we were doing our game together.
To find textures for our game, we used craftpix.net, link in the description. 
We decided to name our game Jump Dude. Also, the game that you are seeing right now is a gameplay the final product.
When we finished little things of the game every day we posted them on github so people could see what we were doing.
I hope you guys liked this video, in the description of the video you will find a link to github repo to download and play the game.
